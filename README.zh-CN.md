# LuckyFuse

Wiki, Manifest, Issue Vacuum

[English](README.md) | **简体中文**

LuckyFuse 是一个 Android 聚合模块，旨在为每一个用户带来好运

Good Luck 4 U, name inspired from [LuckyPatcher](https://www.luckypatchers.com/)


## 前置条件

- 在对应LSPosed管理器勾选模块作用域
- 在LuckyFuse内勾选所需的项。

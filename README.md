# LuckyFuse

Wiki, Manifest, Issue Vacuum

**English** | [简体中文](README.zh-CN.md)

LuckyFuse is an Android aggregation module, built to bring good luck to every user.

Good Luck 4 U, name inspired from [LuckyPatcher](https://www.luckypatchers.com/)


## Prerequisites

- Enable the module scope in your LSPosed manager
- Enable the items you need inside LuckyFuse
